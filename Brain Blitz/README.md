# 🧠 Brain Blitz

## 📌 Introduction
Brain Blitz is a quiz-based game where players test their basic knowledge by answering quick and interactive questions.

> ⚠️ Note: The game and its UI are not fully complete. This project was mainly built to practice UI/UX design and game flow structuring. The game is playable and demonstrates its core concept.

---

## 🎯 Objective
- Answer questions correctly  
- Test knowledge  
- Achieve a high score  

---

## 🕹️ Game Mechanics

### Core Gameplay
- Player is shown a question  
- Multiple options are displayed  
- Player selects an answer  
- System checks correctness  

### Scoring System
- Points for correct answers  
- Optional bonuses (time/streak)  

### Game Flow
1. Start Screen  
2. Question appears  
3. Player selects answer  
4. Feedback (Correct/Incorrect)  
5. Next question  
6. Final score screen
