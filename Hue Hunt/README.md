# 🎨 Hue Hunt

## 📌 Introduction
Hue Hunt is a color-based puzzle game where players test their perception and reaction skills by identifying the correct shades from a set of colors.  

> ⚠️ Note: The game and its UI are still under development. The main purpose of this project is to practice UI/UX setup and color-based game mechanics. Despite being a work in progress, the game is fully playable.

---

## 🎯 Objective
- Identify the correct color from a set
- Improve visual perception and reaction time
- Achieve the highest possible score

---

## 🕹️ Game Mechanics

### 1. Core Gameplay
- Player is shown a group of colored tiles
- One tile differs slightly from the others
- Player must select the tile that stands out
- System checks correctness

### 2. Scoring System
- +3 Points for correct selection
- Time bonus for quick picks
- -1 Penalty Points for incorrect selections

### 3. Game Flow
1. Start Screen
2. Color grid appears
3. Player selects a tile
4. Feedback (Correct/Incorrect)
5. Game Over
6. Final Score Screen
