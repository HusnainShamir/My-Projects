# 🧊 Cube Dash

## 📌 Introduction
Cube Dash is a fast-paced endless runner game where players control a cube and dodge incoming obstacles to survive as long as possible.

> ⚠️ Note: The game and its UI are still under development. This project was mainly created to practice game mechanics and UI/UX structuring. Despite being incomplete, the game is playable.

---

## 🎯 Objective
- Avoid obstacles  
- Survive as long as possible  
- Achieve the highest score  

---

## 🕹️ Game Mechanics

### Core Gameplay
- Player controls a moving cube  
- Obstacles appear in the path  
- Player must dodge or jump  
- Collision results in game over  

### Scoring System
- Score increases over time  
- Game ends on collision  

### Game Flow
1. Start Screen  
2. Game starts (cube moves)  
3. Obstacles spawn  
4. Player avoids obstacles  
5. Collision  
6. Game Over screen
